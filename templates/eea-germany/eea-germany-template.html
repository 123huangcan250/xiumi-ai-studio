使用步骤

  1. 在右侧手机预览中找到模块，点「📋 复制此模块到公众号」。
  2. 到公众号后台图文编辑器，光标放到目标位置，Ctrl + V。
  3. 直接在后台改文字；点图片「替换」换成自己的照片（比例见下表）。
  4. 嵌套：先粘贴「大型自适应文本框」，再把光标放进它的正文里，粘贴任意图片模块或引用卡片。
  5. 图注可整段删空，图标会撑住高度，边框不会塌。

公众号兼容说明

尚未在公众号后台实测。粘贴效果需要你登录后台验证，建议先在草稿里粘贴刊头和文本框两个最复杂的模块。

没有使用 <defs>/<pattern>/渐变 id：公众号编辑器会清除 id 属性，依赖 id 引用的渐变、图案会整块失效。渐变改用容器的 CSS linear-gradient（失效时退回纯色），方格纸与刻度用虚线技巧逐线绘制。

可编辑的文字（标题、正文、图注、铭牌信息）都在 HTML 里；SVG 里的英文丝印、坐标、路线站名属于装饰，后台无法直接改，需要在本文件 build.mjs 中修改后重新生成。

风机叶片、相量、能量脉冲、指示灯使用 SVG 动画；若被过滤会静止显示，不影响排版。

未使用 position:absolute、CSS Grid、class、<style>；多图全部用 flex。
