# XIUMI AI Studio

可视化的微信公众号图文编辑器：拖拽模块排版，导入文稿和照片自动生成版式，可接入 AI 模型，导出到公众号或秀米。

![三套版式](docs/screenshots/three-layouts.png)

## 队员使用（Windows，不需要安装任何开发工具）

### 系统要求

- Windows 10 / 11，64 位
- Edge 或 Chrome 浏览器（编辑器在浏览器里打开）
- 约 120 MB 程序空间，另加你的项目和图片所占空间

### 获取

向负责人领取 `XIUMI-AI-Studio-<版本>-win-x64.zip`（约 41 MB）。这是一个**便携文件夹的压缩包**，不是单个 exe：程序需要旁边的 `app` 文件夹。
可选：用负责人提供的 SHA-256 核对文件。

### 启动与关闭

1. 把 zip **完整解压**到任意文件夹（不要在压缩包里直接双击）。路径含中文或空格没有关系。
2. 双击文件夹里的 **XIUMI AI Studio.exe**。会出现一个黑色窗口，几秒后默认浏览器自动打开编辑器。
3. 第一次运行如果出现“Windows 已保护你的电脑”：点「更多信息」→「仍要运行」（程序没有数字签名）。
4. **关闭**：关掉黑色窗口，或点编辑器右上角「⏻ 退出」。

- 黑色窗口就是程序本身，使用期间保持打开。
- 浏览器没自动打开时，把黑色窗口里“已启动：”后面的地址复制到浏览器。
- 已经在运行时再次双击，会直接打开已有页面，不会启动第二个。
- 需要桌面图标：右键 exe →「发送到」→「桌面快捷方式」（不要把 exe 单独复制出去）。

### 第一次使用

- 「✨ AI 一键排版」→「载入样例」可以先看效果：约 2000 字的活动推文和 10 张图，生成三套版式。
- 不配置 AI 也能用：按内置规则排版。
- 写好后点「导出 / 发布」→「复制到剪贴板」，到公众号后台编辑器里粘贴。

### 数据保存与备份

| 内容 | 位置 |
|---|---|
| 项目、历史版本、模板、组件、主题、素材、AI 设置 | `%LOCALAPPDATA%\XIUMI AI Studio`（工具栏「💾 数据」里可以看到完整路径并打开） |
| 公众号接口配置 | 同一文件夹里的 `.env` |
| 日志（已去掉密钥） | 同一文件夹里的 `logs` |

- 删除、移动或更新程序文件夹，**都不会删除数据**。
- **备份**：「💾 数据」→「下载备份（zip）」。备份不含 AI 密钥和公众号 AppSecret。
- **换电脑 / 恢复**：在新电脑上「💾 数据」→「从备份恢复」，先显示将导入的内容，确认后才写入；本机已有的同名内容保留，不会被覆盖。恢复后要重新填写 AI 密钥。
- **从旧版本迁移**（以前用 `pnpm` 从源码运行的同学）：「💾 数据」→「从旧版本迁移」，填写旧的项目文件夹（或其中的 `data` 文件夹），先「检测」查看来源、目标和数量，再「确认迁移」。只复制、不覆盖，原文件保持不变；AI 设置（含密钥）和 `.env` 一起在本机复制。
- **更新程序**：把新版本解压到新文件夹，用新的 exe 启动，数据自动沿用；旧文件夹可以删除。
- **彻底卸载**：删除程序文件夹；不再需要数据时再删除 `%LOCALAPPDATA%\XIUMI AI Studio`（删除前先备份）。

### 可选配置

这些功能依赖外部服务，打包不能替代它们的前提条件。

- **AI 模型**：工具栏「⚙ AI 模型」添加 DeepSeek、通义千问、Kimi、智谱、豆包、OpenAI、Claude、Gemini 或任意 OpenAI 兼容接口，填写服务商的 API 密钥。需要联网，费用按服务商计。密钥只保存在本机，界面上打码显示。填好地址和密钥后会自动读取上游的模型列表（模型名称框里直接选），并带出上下文长度、最大输出等参数；「检测支持的强度」会逐个试探这个模型接受哪些思考强度（会发几条极短的请求），选中的强度随每次请求发送；第三方接口有特殊开关时，可在「高级」里填额外的请求参数（JSON）。服务拒绝某个参数（如 temperature、max_tokens、reasoning_effort）时会按报错自动去掉重试。
- **公众号草稿箱 / 微信图床**：「💾 数据」→「公众号接口」打开配置文件，填写 `WECHAT_APPID`、`WECHAT_APPSECRET`，保存后重启程序。还需要在公众号后台「设置与开发 → 基本配置」把本机出口 IP 加入白名单，并且账号要有草稿箱接口权限。推送前会再次确认，只创建草稿，不会群发。

### 发布到公众号或秀米

- **复制粘贴到公众号后台**：已由使用者实测可用。
- **导入秀米**（「导出 / 发布」→「导入秀米」）：秀米的“导入 HTML”需要秀米 VIP。根据使用者实测，秀米不接受内嵌在 HTML 里的图片（会变成占位图；实测一张 1.1 MB 的图片连位置一起消失），只接受 https 图片地址：
  - 配置了公众号接口：先把本地图片上传到微信图床，再下载 HTML 导入，图片可直接显示。
  - 没有配置：下载“HTML 和图片包”，导入后在秀米里按编号手动替换图片。
  - 背景图（如轮播）导入后能显示，但在秀米里不能单独选中编辑。
- **人工验证范围**：公众号后台的粘贴效果和秀米导入只做过使用者的人工抽查；草稿箱接口没有用真实公众号测试过；SVG 和动效在秀米中的保留情况没有逐项记录。发布前请在手机上预览。详见 [微信兼容性测试](docs/03-wechat-compat-test.md) 和 [秀米互通实测](docs/05-xiumi-compat-probe.md)。

### 常见问题

| 现象 | 处理 |
|---|---|
| 黑色窗口提示“找不到程序文件” | 没有完整解压，或只复制了 exe。重新完整解压，在解压出的文件夹里运行 |
| 提示端口被占用、地址变了 | 程序已自动换用其他端口，按黑色窗口里的新地址访问 |
| 所有端口都被占用 | 关闭占用端口的程序后重试 |
| 杀毒软件拦截 | 程序没有数字签名，可能被误报；请向负责人确认来源后放行 |
| 想只放大文章 | `Ctrl + 滚轮`、`Ctrl + +/-`、`Ctrl + 0` 只缩放中间的文章（右下角有缩放条），不会缩放整个界面；左右侧栏的边可以拖动调整宽度，双击恢复默认 |
| AI 修改了整篇文章 | 在画布上先点选一个模块，右侧「AI 设计」里默认只改选中的模块，超出范围的修改会被忽略；要改全文就切到「整篇文章」 |
| AI 报错 | 「⚙ AI 模型」里点「测试连接」查看服务商返回的错误（密钥、余额、网络） |
| 推送草稿箱报 IP 白名单错误 | 在公众号后台加入本机出口 IP |
| 程序异常 | 黑色窗口里有中文提示；把 `logs` 里当天的日志发给负责人（日志不含密钥） |

## 功能

- **编辑**：13 种模块，拖拽插入、排序、复制；双击正文就地编辑富文本；撤销/重做；自动保存；历史版本（每个项目最近 50 个）
- **清华电机 · 德国实践套件**：大型文本框、轮播、图片框、双图/三图/四图版式和配套主题
- **AI 一键排版**：导入 Word / Markdown / TXT 和照片，生成三套内置版式，配置 AI 后再生成三套 AI 设计方案；一键生成文案、按照片描述补充文案、按标准名称套用模板、照片安排
- **导入公众号推文**：粘贴链接或正文，保留原样式（可拆分、改字、换图）或提取内容重新排版，可保存为模板（导入前需确认版权）
- **模板与组件库**：模板收藏、组件跨模板收藏与检索，均只存本机
- **主题**：6 套主题，可微调并另存；参考风格学习生成原创主题
- **素材**：自动纠正方向和压缩、裁剪另存、按比例智能裁切、封面设计
- **AI 设计助手**：自然语言修改，逐条审阅接受/拒绝；另有离线规则动作
- **导出**：Markdown、编辑器 JSON、微信 HTML、富文本剪贴板、导入秀米的 HTML 与图片包、公众号草稿箱（需确认）

## 开发与打包

需要 Node.js ≥ 22 与 pnpm。源码运行时数据在仓库的 `data/`，配置在仓库根目录的 `.env`（参考 `.env.example`）。

```bash
pnpm install
pnpm dev              # http://localhost:5173（API 在 127.0.0.1:5174）
pnpm check            # ESLint + TypeScript + Vitest
pnpm e2e              # Playwright（源码模式）
pnpm package:win      # 生成 release/XIUMI-AI-Studio-<版本>-win-x64/ 和 .zip
pnpm verify:package   # 在含中文和空格的临时路径中运行打包产物并逐项检查
pnpm e2e:package      # 用同一套 Playwright 用例测试打包好的 exe
```

打包方式：内置固定版本的 Node.js 运行时（下载后校验 SHA-256）做成启动 exe（Node 单文件应用），服务端用 esbuild 打包，sharp 的 Windows 原生库随包携带；前端由 Vite 构建。依赖版本由 `pnpm-lock.yaml` 锁定。启动器只监听 127.0.0.1，并拒绝非本机 Host 和跨站写请求。

```
src/core/      文档模型、主题、编译器、版式、结构抽取（无 UI 依赖）
src/editor/    React 编辑器
server/        paths.ts 路径与配置 · app.ts 接口 · index.ts 源码入口 · launcher.ts 打包入口 · dataTools.ts 备份迁移
scripts/       样例生成、打包与产物验证
packaging/     图标与随包使用说明
tests/         unit（Vitest）与 e2e（Playwright）
```
