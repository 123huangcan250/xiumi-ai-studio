# XIUMI AI Studio

可视化微信公众号图文编辑器 + AI 自动排版。三栏编辑（模块/素材/模板/项目 · 手机画布 · 样式/主题/AI/参考风格），所有编辑与 AI 修改都作用在结构化文档 JSON 上，由专用编译器输出全内联样式的微信 HTML。

## 快速开始（Windows）

需要 Node.js ≥ 22.19（推荐 Node.js 24 LTS）与 pnpm。

```bash
pnpm install
pnpm sample   # 生成验收样例：约 2000 字活动推文 + 10 张图
pnpm dev      # http://localhost:5173 （API 在 127.0.0.1:5174）
```

生产方式运行：`pnpm build` 后 `pnpm start`，访问 http://127.0.0.1:5174 。也可双击 `start.bat`。

可选配置：复制 `.env.example` 为 `.env`，填写大模型（DeepSeek / MiMo / MiniMax 等 OpenAI 兼容接口，或 Anthropic）与公众号 AppID/AppSecret。不配置时使用内置规则排版，复制粘贴发布不受影响。

验收样例（约 1,900 字 + 10 张图）自动生成的三套版式（E2E 截图基线，左起：叙事长文 / 信息卡片 / 图集故事）：

## 功能

| 功能 | 说明 |
|---|---|
| 13 种模块 | 封面、章节标题、正文、卡片、引言、图文分栏、单图、相册、时间轴、数据表、人物介绍、分割装饰、结尾署名；拖拽插入/排序、复制、收藏为模板 |
| 清华电机 · 德国实践套件 | 左侧「模块」最上方：**大型文本框**（紫色铭牌 / 线框 / 浅底三种样式；其他模块可点击或拖入框内，自动适配框的宽度、14 号黑色正文、12 号灰色注释和间距，也可移出）、**轮播**（左右滑动，露出下一张或整张）、**图片框**（三色框 / 电路角框 / 车票）、**双图 / 三图 / 四图**（各两种版式）。每张图都有图注位置，可留空；空图片位在画布中显示占位，可直接把素材拖上去。视觉元素：清华紫、德国黑红金细条、电机系三相正弦波。「套用配套主题」切换到「清华电机·德国」主题 |
| 富文本 | 双击正文类模块就地编辑（tiptap），加粗/斜体/下划线/高亮/主题色/列表/居中/链接 |
| AI 模型设置 | 工具栏「⚙ AI 模型」：DeepSeek、通义千问、Kimi、智谱、豆包、MiniMax、MiMo、OpenAI、Claude、Gemini、OpenRouter、硅基流动、Ollama 或任意 OpenAI 兼容接口；可保存多套、一键切换、测试连接；填好地址和密钥后点击获取模型列表，在可见列表中选择并带出上下文、最大输出，可显式检测并选择思考强度（检测可能产生 API 费用），第三方接口的特殊开关可在「高级」里填额外请求参数；密钥只存本机并打码显示 |
| AI 一键排版 | 导入 Word/Markdown/TXT + 照片 → 结构抽取 → **AI 设计三套方案**（模型决定配色、衬线/无衬线、字号行距、模块风格和逐章节版式，可填写风格要求、重新设计）+ 三套内置版式 |
| 一键生成文案 | 「AI 一键排版」里的「✍ 一键生成文案」：输入活动描述，选文风（新闻通讯、温暖叙事、青春活泼等，或自己描述）、篇幅和标题级数，生成带标题级别的完整文案（# 标题、## 一级标题、### 二级标题）。可直接修改、按意见重写、导入正文框；会提示套话和【待补充】占位（描述里没有的信息模型不应编造，需要你补真实内容） |
| 套用模板 | 模板里的每个模块、收藏的每个组件都有**标准名称**（封面标题、一级/二级/三级标题、正文段落、大型容器、单图、双图左右、双图上下、双图不对称一大一小、三图一大二小、三图并排、四图对称布局、图片轮播、分割装饰、结尾署名等），自动识别，可在模板「模块」里查看、修改。套用时按文案结构逐项取模块：标题按级别用对应标题模块，正文用正文段落（没有时整章装进大型容器），只替换文字和照片，不临时生成新版块。可同时从收藏组件选模块，**同一个标准名称只用一个模块**。文案标题级数多于标题模块时先提示增加模块或减少级数 |
| 照片安排 | 勾选几张照片组成一组，自动选对应张数的版式（也可指定）；可指定照片或组放在文案某一句话后面；同一句后面有多张单独的照片时询问：逐张单图、组成多图（选版式），或用自然语言交给 AI。其余照片由 AI 按照片描述放到对应段落（没有 AI 时按章节平均分配） |
| 导入公众号推文 | 工具栏「⤓ 导入推文」：粘贴文章链接或复制正文粘贴；**保留原样式**（拆成可拖动、双击改字、可换图的“原文片段”；整节内容包在一张卡片里时会拆开卡片，轮播单独成块；以前导入的大模块可选中后点 ✂ 拆开，可撤销）或**提取内容重新排版**；可同时保存为模板、提取配色为主题。导入前需勾选确认版权 |
| 6 套主题 | 清华紫、科技蓝、人文暖色、极简杂志、青春活力、清华电机·德国；颜色/字号/行距/间距/圆角可微调并另存 |
| AI 设计助手 | 自然语言指令 → 操作列表（insert/update/remove/move/setTheme）→ 差异审阅，逐条接受/拒绝；选中模块时默认只更新这个模块（可切回整篇）；越界操作整批拒绝，生成期间文档变化需重新生成；另有 4 个离线规则动作 |
| 参考风格学习 | 对有权使用的文章提取颜色、字号层级、行距、间距、圆角、装饰倾向，生成新的原创主题 |
| 素材 | 上传自动纠正方向并压缩、裁剪另存、相册按统一比例智能裁切、封面设计器（900×383） |
| 组件库 | 左侧「组件」：跨模板收藏（收藏时必须确认标准名称）、检索（名称、标签、文字、来源、标准名称）、按标准名称、类别和色系筛选，点击或拖入画布；双击原文模块编辑文字时，点击组件会插到光标所在段落后面，宽度和收藏时一样。大版块可按结构拆分，也可在画布上点选一部分（⌖）。插入时可统一到本文配色。秀米轮播的背景图可替换。组件只存本机，不提供分享 |
| 项目 | 自动保存、历史版本（50 个）、撤销/重做（Ctrl+Z / Ctrl+Y）、模板收藏 |
| 导出 | Markdown、编辑器 JSON、微信 HTML、富文本剪贴板（内嵌图片 / 上传微信图床 / 原链接） |
| 草稿箱 | 配置公众号接口后，二次确认才会上传图片并创建草稿（不会群发） |

## 测试

```bash
pnpm check   # ESLint + TypeScript + Vitest 单元测试
pnpm e2e     # Playwright：验收流程 + 剪贴板 + 截图回归（首次运行生成基线）
```

**微信兼容性**：自动化测试只覆盖静态规则、HTML 结构与剪贴板内容；**在微信公众号平台验证过部分功能，目前最建议的方法是在xiumi-ai-studio平台导出HTML文件，然后导入xiumi平台，之后同步到微信公众号**，。请按 [docs/03-wechat-compat-test.md](docs/03-wechat-compat-test.md) 人工测试并记录。

## 目录

```
src/core/      文档模型、主题、编译器、版式配方、结构抽取、ops、风格提取（无 UI 依赖，可单测）
src/editor/    React 编辑器
server/        Express：项目/版本/模板/主题落盘、素材(sharp)、导入(mammoth)、AI 代理、微信接口
tests/         unit（vitest）与 e2e（playwright）
docs/          调研选型、兼容测试、多 Agent 流程
data/          本地数据（不入库）
```
