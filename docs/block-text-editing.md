# 双击编辑模块文字

在画布上双击图片、双图/三图、轮播、相框等模块，可直接编辑图注或标签；空图注也会提供输入框。标题、封面、引言、人物、结尾、时间线、表格和文本框也支持编辑对应文字字段。

原有模块预览保留在编辑框上方，修改即时保存，可通过撤销恢复。点击“完成”或按 Escape 关闭编辑框（不会撤销已保存修改）。嵌套模块双击只编辑该模块，不会同时打开父文本框。

编辑图注不会替换图片、改变图片引用或重建版式。段落、卡片和图文模块仍使用原来的富文本编辑器，HTML 模块仍使用原来的代码编辑器。图片像素中已有的文字不是独立文本字段，不能通过这个功能修改。

## 封面标题居中

封面是独立模块，不是正文段落。单击封面后，右侧“模块”面板的“封面标题对齐”可选左对齐、居中、右对齐或跟随版式；也可双击封面，在文字编辑框里使用同一设置。无需拖选标题中的字符。

这只改变封面的主标题，不改变小标签、副标题、时间地点、图片和装饰。AI 设计中选择“仅选中模块”，输入“标题改为居中”，生成建议并接受后也使用同一标题对齐字段。AI 输出仍需检查并接受；手动设置不需要模型请求。
