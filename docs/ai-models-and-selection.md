# AI 模型发现与选中模块修改

## 模型设置

在「AI 模型设置」填写 Base URL 和密钥，点击「从服务商获取模型列表」。服务端请求该配置的 `/models`；Anthropic 使用 `/v1/models`（Base URL 可包含 `/v1`）。密钥不会放进 URL，发现请求不会跟随重定向。获取成功后会直接显示可滚动的「可用模型」列表，点击即可填写模型名称及已提供的上下文窗口、最大输出和思考强度列表；无需再点输入框展开建议。选择模型后也可继续手动输入任意模型 ID。

只有上游实际返回的元数据才会导入：`context_length` / `context_window` / `max_context_length` 以及 `reasoning_efforts`。标准 OpenAI 模型列表通常只返回 ID，不提供上下文窗口或思考强度；此时请按服务商文档手动填写，不从模型名称猜测。上下文窗口仅作为配置记录，不会截断或扩充输入。Anthropic 发现最多读取 5 页，每页请求最多 1000 条；其他接口使用单次模型列表响应。未列出的模型仍可手动填写。最大输出会限制单次请求的 token 上限。

思考强度留空时保留现有请求行为。填写时：

- OpenAI 兼容接口发送 `reasoning_effort` 和 `max_completion_tokens`。
- Anthropic 发送 `output_config.effort`，输出上限仍为 `max_tokens`。
- 两种接口均不发送 `temperature`，避免与部分思考模型冲突。

强度是可编辑字符串，建议值不代表服务商已支持。自定义网关必须兼容所选接口参数；若只支持专有 thinking 开关或 token budget，当前不会自动转换。错误会显示，不会静默降级思考强度。请在保存后测试连接。更换服务地址 origin 或接口类型后，必须重新填写密钥，不能把之前保存的密钥自动发送到新服务。

可点击“检测思考强度”发送短测试请求，可能产生 API 费用；不会自动探测。高级额外参数接受 JSON 对象中的服务商专用选项，但不能覆盖模型、消息、工具、流式设置、输出上限、温度、思考强度或 JSON 模式。切换模型时会清空旧模型的能力元数据。

## 精确修改

在画布点选模块后打开「AI 设计」，默认范围为「仅选中模块」，界面显示模块类型和 ID。AI 收到选中模块的完整内容及其他模块的简短摘要，但只允许返回该 ID 的 update。服务端拒绝跨模块、全文主题、插入、删除或移动等越界操作；不会把越界结果变成待接受的建议。选择「全文」后才恢复原来的全文操作能力。

修改仍需逐条或全部接受，可以撤销。请求期间若文档发生变化，会要求重新生成，避免把旧建议应用到新正文。范围为整个模块，不是富文本中任意字符选区；导入的 HTML 原文片段仍以模块的文字槽位进行修改。

## 验证

单元测试覆盖模型发现元数据、参数透传、设置持久化、密钥作用域、选中模块提示词和越界结果拒绝。`tests/e2e/ai-issues.spec.ts` 覆盖模型设置持久化和画布选择到 AI 请求的传递，可通过 `pnpm e2e tests/e2e/ai-issues.spec.ts` 运行。真实服务商的能力和返回格式需使用用户自己的配置验证；测试不会调用付费模型。
