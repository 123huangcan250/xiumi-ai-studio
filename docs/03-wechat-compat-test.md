## 人工粘贴测试步骤

1. `pnpm dev`，打开 http://localhost:5173 ，「AI 一键排版」→「载入验收样例」→ 生成三套排版。
2. 分别打开 A / B / C，每套切换 5 个主题中的至少 2 个。
3. 「导出 / 发布」→「复制到剪贴板」，图片模式分别测试「内嵌图片」与（已配置时）「上传到微信图床」。
4. 登录公众号后台 → 新建图文 → 在正文区 Ctrl+V。
5. 用后台「预览」发送到手机，对照本工具「手机预览」逐项检查，填写下表。
6. 截图保存到 `docs/compat-screens/日期-版式-主题-客户端.png`。

## 重点观察的风险点

- **内嵌 base64 图片**：后台是否自动转存为 mmbiz 图片；若失败，改用「上传到微信图床」。
- **两栏（`display:inline-block` + `font-size:0` 父容器）**：图文分栏、相册、人物介绍是否换行错位。
- **`box-shadow`、`border-radius` 在图片上**：是否被剥离。
- **继承样式**：正文字号/行距/颜色只写在根 `<section>` 上；在后台编辑器中新增段落是否继承。
- **列表**：已统一渲染为带符号的段落，避免 `ul/ol` 缩进问题。
- **外链**：非 mp.weixin.qq.com 链接已转为“文字（网址）”。

## 草稿箱接口测试步骤

1. 在项目根目录 `.env` 填写 `WECHAT_APPID`、`WECHAT_APPSECRET`（由你本人填写，不要提交到 Git）。
2. 公众号后台「设置与开发 → 基本配置 → IP 白名单」加入本机出口 IP。
3. 重启 `pnpm dev`，在文章面板设置封面 →「导出 / 发布」→「推送到草稿箱…」→ 勾选确认 → 推送。
4. 到后台草稿箱检查内容；接口只创建草稿，不会群发。
5. 注意：接口正文上限 2 万字符（含标签与内联样式），导出面板会显示长度。
